# SkillTree

Дипломный проект платформы образовательных траекторий по компетенциям. Первая аудитория — разработчики. Разработка идёт по модулям 0–18, публикация в Sites исключена. Срок первой части — 30 октября 2026 года; ориентир пользователя — около 50% проекта, рабочий объём планирования — модули 0–10.

Клиент: React + TypeScript + Vite, React Flow и собственная компоновка. Для будущего сервера выбраны NestJS, PostgreSQL и Prisma; сервер, аккаунты и сохранение пока не реализованы.

## Текущий экран

Сверху — навигация по модулям, под ней карта занимает всю оставшуюся область окна. Карточка появляется только при выборе темы и находится внутри карты: справа на широком экране, снизу на узком. Остальные разделы пока содержат заголовок и статус разработки.

В центре — «Начало», вокруг — пять специальностей: Middle React, Vue, Node.js, Python и Java. Нажатие раскрывает только выбранный путь: 51, 52, 40, 35 и 37 тем соответственно. При переключении прежняя ветка исчезает, новая появляется по частям. Камера вписывает фактический размер выбранного пути. Типы сложности, кольца и поля размещения удалены.

В каталоге 108 компетенций и 5 профессий. Общие темы используют единые ID; разные языки и фреймворки независимы. Траектории состоят из 20–21 учебного блока с вкладками тем. На карте только короткие переходы к соседним шагам; все настоящие предпосылки и материалы находятся в карточке. [Состав пяти профилей](docs/FIVE_CAREERS.md).

Путь идёт от основ к проекту, параллельные блоки входят в траекторию. Тупиковых учебных блоков нет. Небольшой постоянный разброс координат делает расположение свободнее. Связи — прямые отрезки между краями кругов; порядок предпосылок и безопасные расстояния сохраняются.

## Запуск

Проверено на Node.js 25.0.0 и npm 11.6.2, Windows. Проект использует npm workspaces, зависимости зафиксированы в package-lock.json.

```powershell
cd C:\Projects\SkillTree
npm ci
npm run dev
```

Открыть http://127.0.0.1:5175/. Сервер доступен локально.

## Что проверить

1. В обзоре находятся только начало и специальности.
2. Нажать React: раскрывается его путь, Vue-технологий на карте нет.
3. Переключиться на Vue: прежняя ветка исчезает, раскрывается новая. Повторить несколько быстрых нажатий.
4. Найти «эффекты»: откроется нужная тема в группе React, при необходимости сменится профессия.
5. Переключить вкладки блока и проверить материалы/предпосылки. Выбор подсвечивает соседние переходы, длинные стрелки не появляются.
6. Проверить Node.js, Python и Java через кнопки либо поиск; найти NestJS, Pydantic или Spring Web и открыть вкладки.
7. Вернуться через «Специальности» или «Начало»: снова остаются шесть кругов.

Колесо перемещает карту, кнопки +/− меняют масштаб, «Вся траектория» вписывает ветку. Уменьшение движения учитывается. На узком экране карточка закреплена снизу внутри карты; выбранная вершина остаётся выше неё.

Класс `Vertex` не содержит типов сложности и координат. Данные создаются в тематических файлах `packages/graph-domain/src/nodes/`, полный каталог собирается в `skill-catalog.ts`. `frontend-catalog.ts` сохраняет исходную пару профессий для сравнений и исторических тестов. Внешнего API пока нет.

## Проверки

```powershell
npm test
npm run build
npm run test:browser
```

54 проверки модели/геометрии и production-сборка проходят. Отдельный браузерный набор обновлён под текущий интерфейс; статус его запуска и ручной проверки указан в [отчёте](docs/LAYOUT_VALIDATION.md).

Прежние прямоугольные и радиальные раскладки, измерения 100/300/800 и модель колец сохранены как история. Они не считаются нагрузочными показателями текущей сцены.

Следующая проверка архитектуры — сохранение общей технологии, личного графа и записей в PostgreSQL. До неё пункт 0 целиком не считается завершённым.
