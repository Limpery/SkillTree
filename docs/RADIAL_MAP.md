# Радиальная карта профессий

> Историческая версия. Последнее уточнение отменяет типы сложности и кольца. Текущая реализация: [карта с раскрытием специальности](CAREER_MAP.md).

20 октября 2026 года. По уточнению пользователя прямоугольные уровни заменены круговой географией: база в центре, области знаний вокруг неё, профессии на периферии своего направления.

## Что отображается

Состав каталога сохранён: 60 компетенций, 2 профессии, 43 общие темы. После группировки отображается 101 связь. Заполнен фронтенд-сектор внизу: React и Vue. Остальные подписи обозначают место для будущего наполнения, а не готовые профессии или результаты анализа рынка.

Пример расположения направлений:

| Направление | Положение |
| --- | --- |
| Big Data | Сверху |
| Аналитика | Справа сверху |
| Базы данных | Справа |
| Бэкенд | Справа снизу |
| Фронтенд | Снизу |
| Инженерия и проектирование | Слева |

Углы и принадлежность профессии сектору задаются в `RadialLayoutOptions`, отдельно от предметных зависимостей. Эти значения можно менять без переписывания учебного каталога.

## Размещение и линии

`layoutTypedKnowledgeGraph` в `packages/graph-domain/src/typed-graph.ts` закрепляет каждый тип вершины за собственным кольцом: основы → лёгкий → средний → сложный → проект → специальность. Коллизии исправляются по углу, без выхода из кольца. Общие темы распределены вокруг центра, специальные темы находятся в секторе профессии. [Модель и группировка](TYPED_VERTICES.md).

Расстояние от центра помогает с навигацией и сложностью темы, но не заменяет предварительные требования. Все обязательные зависимости остаются в данных; несколько входов означают ALL. Общие технологии сохраняют единые ID.

Избыточные транзитивные линии сокращаются так же, как в предыдущей версии. Остальные соединения прокладываются по графу видимости вокруг увеличенных препятствий и сглаживаются. Проверки измеряют расстояние до кругов с запасом, превышающим радиус сглаживания. Линии могут пересекать другие линии; выбор темы или профессии выделяет нужные связи.

Прежняя `layoutKnowledgeGraph` с ELK остаётся для исторических тестов и сравнения. Активный экран использует радиальный алгоритм. Production-сборка больше не включает ELK-модуль.

## Работа с картой

- «Обе ветки» / «Весь граф» показывают окружность целиком.
- «Начало» и центральная кнопка приближают общую базу.
- «Развилка» показывает React и Vue, «Профессии» — конечные цели.
- Выбор специальности подсвечивает её путь; поиск и карточка продолжают работать с теми же ID.
- На обзоре остаются главные ориентиры и направления. В модели 62 вершины, на карте 47 кругов, включая 7 групп. Приближение меняет подписи, но группы не разделяет. Нажатие группы открывает вкладки тем, поиск сразу выбирает нужную.

Вкладка снова доступна; проверены поиск участника группы и переключение вкладок мышью и клавиатурой. Подробности проверок — в [отчёте](LAYOUT_VALIDATION.md).
