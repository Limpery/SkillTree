# Типизированные вершины и постоянные группы

> Историческая версия. Последнее уточнение отменяет типы сложности и кольца. Текущая реализация: [карта с раскрытием специальности](CAREER_MAP.md).

20 октября 2026 года. Реализовано уточнение пользователя: шесть типов, отдельные кольца сложности и группировка без раскрытия по масштабу.

## Модель

`packages/graph-domain/src/vertex.ts` содержит класс `Vertex<T>`. Тип `T` ограничен значениями `foundation`, `easy`, `medium`, `hard`, `project`, `specialty`. Уровень вычисляется из типа и не записывается вторым независимым числом. React-компонент `KnowledgeNode` отвечает только за отображение этой модели.

В конструктор передаются ID, тип, название, тематический раздел, описание, результат обучения, материалы, ID предварительных требований и необязательный `groupingId`. Данные копируются и замораживаются. `toJSON()` возвращает независимый объект для сериализации; `toTopic()` — адаптер для существующих алгоритмов траектории. Ссылки хранятся по ID, без циклических ссылок на экземпляры классов.

Основной файл `frontend-catalog.ts` импортирует фабрики из шести файлов:

| Файл в `packages/graph-domain/src/nodes/` | Тип | Вершин |
| --- | --- | --- |
| foundation.ts | Основы | 4 |
| easy.ts | Лёгкий уровень | 10 |
| medium.ts | Средний уровень | 27 |
| hard.ts | Сложный уровень | 17 |
| project.ts | Проект | 2 |
| specialty.ts | Специальность | 2 |

В каждом файле непосредственно создаются экземпляры `new Vertex(...)` соответствующего типа. `nodes/metadata.ts` задаёт тематические разделы, требования профессий и состав групп. Старый `middle-react.ts` остаётся историческим примером и поставщиком совместимых типов; активный каталог больше не собирается изменением его данных.

При сборке проверяются уникальные ID, существование предпосылок, циклы, направление зависимости по сложности и согласованность групп. Вершина может зависеть от своего или более раннего уровня. Входящие и исходящие связи доступны через `vertex.connections.incoming/outgoing`; оба направления вычисляются из одного списка предварительных требований.

## Кольца

Активная раскладка — `layoutTypedKnowledgeGraph` в `typed-graph.ts`. Каждому типу соответствует отдельное кольцо. Коллизии исправляются только перемещением по окружности; радиус вершины не меняется. В кольцо помещается весь круг, а не только его центр. По мере наполнения кольцо может увеличиваться, последующие кольца смещаются наружу.

Одинаковый уровень не означает независимость тем. Например, основы React и его Hooks относятся к одному кольцу, но обязательная связь между ними сохраняется. Кольцо показывает редакционно назначенную сложность, стрелки — учебные зависимости, сектор — профессию. Уровни можно корректировать по мере уточнения программы обучения.

## Группы

Группировка задаётся явно: `groupingId` у каждой темы плюс запись `VertexGroup` со списком ID. Несовпадение поля и списка, повторное членство, неизвестные участники и смешение типов отклоняются.

Созданы семь групп: рабочая среда, CSS, JavaScript/DOM, TypeScript, React, Vue, тестирование. В модели остаются 62 вершины; отображается 47 кругов. Группа — проекция для карты, не новая компетенция и не новое учебное требование.

Проекция `createGraphView` объединяет внешние линии. Внутренние зависимости остаются в модели и карточках тем; петли группы на карте не рисуются. Сокращение транзитивных линий выполняется до группировки. При произвольном объединении тем возможны встречные внешние линии; это не означает цикл в исходных учебных зависимостях.

Нажатие группы открывает вкладки её участников. Каждая вкладка содержит собственное описание, материалы, предпосылки и следующие темы. Поиск темы сразу выбирает соответствующую вкладку. Поддержаны стрелки влево/вправо, Home/End и управление фокусом. При любом масштабе состав группы одинаков; меняется лишь детализация подписей.
