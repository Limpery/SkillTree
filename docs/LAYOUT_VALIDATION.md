# Проверка учебных блоков и коротких переходов

20 октября 2026 года. Актуальная модель — [одна траектория со смысловыми блоками](CAREER_MAP.md). Ранее сохранённые снимки относятся к предыдущим версиям.

## Модель и сборка

`npm test`: **43 из 43**. Двенадцать проверок относятся к текущей сцене:

- в обзоре только начало и две профессии;
- все 51/52 требования своей профессии присутствуют ровно один раз, без чужого фреймворка;
- у каждого блока есть вход и продолжение до проекта, боковых тупиков нет;
- все настоящие предпосылки сохранены, вкладки внутри блока упорядочены;
- круги отделены, сегменты кривых обходят посторонние круги с запасом более 17 единиц;
- случайные сдвиги не меняют порядок предпосылок и сохраняют параллельные блоки;
- на полотне только соседние переходы, расстояние между центрами и длина маршрута не превышают 640 единиц;
- линии отдельных ветвей не пересекаются;
- повторное построение воспроизводит позиции и линии, каталог не меняется;
- масштаб учитывает фактические границы и экран;
- класс не содержит типов сложности/уровня, проверки зависимостей действуют;
- неизвестная профессия отклоняется без изменения каталога.

Остальные 31 проверка относятся к общему планировщику, независимости профессий и историческим раскладкам. Нагрузочные наборы 100/300/800 прежних алгоритмов не считаются замерами текущей сцены.

`npm run build`: TypeScript и production-сборка проходят.

## Проверка интерфейса

Проверка выполнена через CUA в существующей вкладке `http://127.0.0.1:5175/` на доступном узком экране (DOM: 394 × 668). Подтверждены:

- раскрытие React/Vue: 24 круга, 30 переходов, 51/52 темы;
- смена профессии и отсутствие чужого фреймворка;
- поиск API, три вкладки и сохранённые HTTP/асинхронность в карточке;
- переключение вкладки не добавляет дальние линии;
- Vue-тесты включены в блок тестирования;
- быстрые смены профессий, поиск вкладки фреймворка, возврат к обзору;
- отсутствие горизонтального переполнения.

В DOM React подтверждены 21 блок, 51 уникальная тема и единственная завершающая учебная вершина `middle-project`. [Замер геометрии](measurements/career-blocks-geometry.json): максимальное расстояние между связанными центрами — около 435 единиц для React и 451 для Vue; длины нарисованных маршрутов — около 426 и 449 соответственно.

Актуальные снимки: [ветка целиком](measurements/career-blocks-overview.png), [фрагмент с блоками](measurements/career-blocks-detail.png). [Результаты ручной проверки](measurements/career-blocks-ui-check.json).

Отдельный `tests/frontend.spec.ts` содержит 9 обновлённых сценариев. Он не запускался через отдельный Playwright-процесс в этом проходе; ручная проверка не выдаётся за результат этого набора. Широкий экран, плавность на разных устройствах и пользовательская настройка уменьшения движения не проверялись заново.
