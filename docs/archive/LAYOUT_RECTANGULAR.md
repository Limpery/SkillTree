# Проверка карты React и Vue

Историческая проверка прямоугольной раскладки от 19 октября 2026 года: **60 компетенций, 2 профессии, 43 общие темы, 117 нарисованных связей**. Другие результаты: [одна ветка React](LAYOUT_MIDDLE_REACT.md), [последовательная карта](LAYOUT_SEQUENTIAL.md), [ранние замеры 100/300/800](../GRAPH_VALIDATION.md). Текущая версия использует радиальную геометрию; [актуальный отчёт](../LAYOUT_VALIDATION.md).

## Автоматические проверки

`npm test`: **27 из 27**. Четыре новые проверки двух специальностей подтверждают:

- независимость требований: Vue не требует React, React не требует Vue; нет тем вне обоих путей;
- единый ID для общей технологии и включение общих тем в оба пути;
- одинаковый уровень React/Vue, неизменность каталога и достижимость каждой исходной зависимости после сокращения линий;
- отсутствие наложения кругов и прохождения отрезков через посторонние круги с запасом 3 единицы.

Прежние 23 проверки остаются проверками общих алгоритмов и первой ветки React. Прохождение не означает, что будущие произвольные пользовательские графы уже проверены. Скругление SVG выполняется внутри коридоров ELK.

`npm run build`: TypeScript и production-сборка проходят. Сохраняется предупреждение Vite о крупном отдельном ELK-модуле; время загрузки и FPS новой карты не измерялись.

В `tests/frontend.spec.ts` подготовлены 8 браузерных сценариев. Автоматический запуск обновлённого браузерного набора ещё не выполнен, результат 8 из 8 не заявляется.

## Ручная проверка

В локальном браузере проверены:

- загрузка 62 вершин и 117 линий; карта завершает размещение (`aria-busy=false`);
- общие темы представлены 43 вершинами, React и Vue размещены на одном уровне;
- карточка Vue содержит HTML/CSS/JavaScript и ссылку на официальное руководство;
- выбор пути Vue приглушает React, сохраняя Vue, общие TypeScript и все 62 вершины;
- конечная профессия Vue открывает свой практический проект;
- поиск «vue разработчик» на ширине 390 px открывает Vue-профессию; горизонтального переполнения страницы нет.

Первое размещение разносило React и Vue по краям общей карты. В окончательном варианте их порядок внутри уровня закреплён для сравнения; «Развилка» наводит камеру на два фреймворка. Для чтения всех 62 вершин требуется перемещение и увеличение, а полный обзор служит навигации.
