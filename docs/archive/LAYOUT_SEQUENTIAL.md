# Последовательные маршруты и геометрия SkillTree

Изменение от 19 октября 2026 года по требованию пользователя: выбранная профессия отображается последовательностью учебных шагов. Линии должны обходить посторонние круги, а вершины сохранять расстояние при росте набора.

## Реализация

- Добавлен отдельный профиль React-разработчика. В каталоге 40 тем и 9 профессий.
- React: Git → HTTP → HTML → CSS → основы программирования → JavaScript → TypeScript → React → профессия. Основы программирования включены как сохранённая предварительная тема JavaScript.
- `learningOrder` определяет предпочтение учебного плана, не изменяя технические зависимости технологий. Проверяется корректность порядка каждой предпосылки.
- Любая выбранная профессия отображается одной цепочкой. Число линий равно числу шагов минус один; отсутствует веер связей к профессии.
- На обзоре показывается дерево направлений: радиальные полосы, составные группы, основные ветви к профессиям. Поперечные зависимости доступны в данных и через содержание карточек.
- Позиции вершин вычисляются с расстоянием 220 единиц между шагами. Линии заканчиваются вне кругов. Перетаскивание отдельных вершин в просмотрщике отключено; перемещение всей карты и масштабирование доступны.
- Подписи шагов находятся сбоку от линии. Высота выбранного маршрута растёт с числом шагов; колесо прокручивает страницу и не уменьшает маршрут до нечитаемого размера.

## Автоматические проверки

`npm test`: 17 из 17 пройдены. В том числе:

- порядок React и сохранение обязательных предпосылок;
- невозможность поставить зависимую тему перед её предпосылкой даже при обратном предпочтении;
- одна технология на маршрут и сохранность исходного каталога;
- правильное включение обязательных тем и одного варианта альтернативы;
- все 9 ролей отображаются последовательными цепочками;
- проверка расстояния каждой пары кругов и расстояния от каждой линии до всех посторонних кругов;
- свёрнутое, частично раскрытое и полностью раскрытое представление каждого набора 100/300/800.

`npm run build`: проверка TypeScript и production-сборка проходят.

Первый запуск расширенного браузерного набора: 5 из 7 сценариев пройдены, включая новый маршрут React, раскрытие группы, поиск Java, мобильный экран и сохранение роли при выборе общей темы. Два сценария на 800 вершинах выявили зависание признака готовности после смены набора. Исправлено ожидание применения новых координат и измерения вершин перед настройкой камеры. Повторный запуск полного браузерного набора был отклонён пользователем, поэтому результат 7 из 7 не заявляется.

## Ручная проверка после исправления

Проверено в существующей вкладке локального приложения:

- основной набор переключается на 800: 23 обзорных вершины, исходных тем и профессий ровно 800;
- после переключения карта завершает загрузку (`aria-busy=false`);
- полный режим: 800 вершин в представлении и DOM, карта завершает загрузку;
- возврат к автоматическому режиму и раскрытие JavaScript открывают лишь часть большого набора;
- последовательный React-маршрут читается на узком экране, длинное название основ программирования не накладывается на соседние шаги;
- обзор проверен при ширине 1440: подписи вынесены наружу относительно ветвей.

Проверки пересечений относятся к кругам в подготовленных раскладках, а не к произвольной будущей ручной раскладке редактора. Полный показ 800 отдельных вершин остаётся диагностическим: для чтения требуется увеличение и локальная детализация. Прежние измерения FPS и задержки не перенесены на новую геометрию.
