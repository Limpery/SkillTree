# Проверка графа Middle React

Историческая проверка первой ветки от 19 октября 2026 года: 51 компетенция и 1 конечная профессия. После транзитивного сокращения рисовались 95 связей. Проверки прежней линейной карты сохранены в [архиве](LAYOUT_SEQUENTIAL.md); её замеры не перенесены на эту версию. Актуальная проверка двух профессий — [здесь](../LAYOUT_VALIDATION.md).

## Автоматическая проверка

`npm test`: **23 из 23** пройдены. 17 проверок ранней общей модели сохранены; 6 новых проверок относятся к актуальному DAG:

- одна профессия, все компетенции достижимы из требований финального проекта; описания, результаты и материалы заполнены;
- независимые HTML/CSS/JavaScript стоят на одном уровне и не образуют искусственную цепочку;
- React объединяет HTML/CSS/JS, API объединяет HTTP/асинхронность; HTTP используется несколькими темами;
- транзитивное сокращение сохраняет достижимость каждой исходной зависимости;
- размещение не изменяет каталог и направляет зависимости вниз;
- круги не перекрываются; каждый отрезок маршрута проходит вне всех посторонних кругов с запасом 3 единицы.

Проверяется геометрия подготовленной карты; это не доказательство корректности будущих произвольных графов редактора. SVG скругляет углы радиусом до 14 единиц внутри коридоров ELK.

В `tests/middle-react.spec.ts` подготовлены 6 браузерных сценариев: загрузка, параллельные уровни, карточка React, объединение API, конечная цель/разделы и узкий экран. Автоматический запуск этого нового набора ещё не выполнен; прохождение 6 из 6 не заявляется.

## Ручная проверка

В локальном браузере проверены:

- свежая загрузка всех 52 узлов и 95 линий, завершение размещения (`aria-busy=false`);
- одинаковый уровень и координата Y у HTML, CSS и JavaScript;
- карточка React с тремя предпосылками и официальной ссылкой;
- карточка API с HTTP и асинхронностью, переход к HTTP и его использованию в нескольких темах;
- конечная профессия и обязательный практический проект;
- выбор раздела качества сохраняет все 52 вершины;
- поиск TypeScript на ширине 390 px, корректная карточка и отсутствие горизонтального переполнения страницы;
- сброс прокрутки карточки к началу при смене темы.

`npm run build`: проверка TypeScript и production-сборка проходят. Vite предупреждает о размере отдельного ELK-модуля; это предупреждение не скрыто. Время загрузки и FPS новой карты ещё не измерялись.

Сохранён [снимок параллельных ветвей](../measurements/middle-react-parallel.jpg) на ширине 1440 px. Временные размеры браузера после проверки возвращены к исходным.

## Ограничения

Состав ветки подготовлен вручную; это базовый профиль, а не подтверждённый компаниями стандарт Middle. Аккаунты, личные записи и серверное сохранение не входят в эту реализацию. Ранние FPS на 100/300/800 вершинах относятся к предыдущему представлению и не характеризуют новую раскладку.
