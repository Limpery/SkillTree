# Две специальности: React и Vue

Текущий интерфейс раскрывает одну профессию за раз; [описание сцен](CAREER_MAP.md). Ниже сохранён состав каталога и история сравнения.

С 20 октября экран использует [радиальную карту](RADIAL_MAP.md). Ниже сохранено описание состава двух специальностей; прежние сведения о прямоугольной раскладке относятся к этапу сравнения.

19 октября 2026 года по запросу пользователя к React добавлена специальность Middle Vue-разработчика. В модели **60 компетенций и 2 профессии**. После уточнения от 20 октября семь постоянных групп отображаются как часть 47 кругов со 101 видимой связью; учебные зависимости сохранены. [Класс вершины, типы и кольца](TYPED_VERTICES.md).

## Общая основа и специальные навыки

43 компетенции общие: веб, HTML, CSS, JavaScript, TypeScript, Git, HTTP/API, формы, безопасность, архитектурные принципы, тестирование, производительность и выпуск. Они имеют единые ID и не копируются при выборе профессии.

Общие темы очищены от случайных обязательных зависимостей от React. Например, концепции кеширования API не требуют React-эффектов, а принципы тестирования компонента не требуют React с TypeScript. В проекте общие принципы объединяются с выбранным фреймворком. Это не исключение тестирования или эффектов из требований профессии.

React имеет 8 собственных компетенций: основы, состояние/hooks, эффекты/refs, типизация, композиция, роутинг, store и проект. Vue имеет 9: основы, реактивность, жизненный цикл/watch, типизация, композиция/composables, Vue Router, Pinia, тестирование Vue-компонентов и проект.

Итого путь React включает 51 компетенцию, путь Vue — 52. Ни один путь не включает темы другого фреймворка. Завершение подготовленного профиля не является гарантией трудоустройства или подтверждением универсального уровня Middle.

## Поведение экрана

- Общие вершины оливковые, React — голубые, Vue — бирюзовые. Подписи и легенда дополняют цвет.
- «Обе ветки» / «Развилка» показывают два фреймворка рядом. «Начало» возвращает общую базу, «Профессии» показывает обе конечные цели.
- Переключатель специальностей подсвечивает весь путь и приглушает соседнее направление, сохраняя его на карте.
- Выбор конечной профессии подсвечивает её обязательные темы и открывает карточку с практическим проектом.
- Выбор обычной темы показывает её непосредственные предпосылки и продолжения. Поиск использует варианты названия соответствующей роли.
- Разделы и миникарта помогают перемещаться по общему графу. На полном обзоре мелкие подписи требуют приближения.

Каталог: `packages/graph-domain/src/frontend-catalog.ts`. Принадлежность вершины пути вычисляется по замыканию требований роли, а не задаётся отдельной копией темы. Раскладка ELK сохраняет порядок объявленных вершин внутри уровня для сравнения двух фреймворков; уровни и связи определяются предпосылками.

## Источники и проверка

Подборка Vue сверена с официальными материалами: [введение](https://vuejs.org/guide/introduction.html), [TypeScript](https://vuejs.org/guide/typescript/composition-api.html), [Vue Router](https://router.vuejs.org/introduction.html), [состояние и Pinia](https://vuejs.org/guide/scaling-up/state-management.html), [тестирование](https://vuejs.org/guide/scaling-up/testing.html). Содержание подготовлено вручную; API курсов и вакансий не подключены.

Автоматическая проверка включает независимость профессий, общие ID, достижимость зависимостей, параллельное размещение и отсутствие пересечений кругов с посторонними линиями. Детальный статус: [проверка раскладки](LAYOUT_VALIDATION.md).
